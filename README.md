# StayPunch360

Hotel, resort and accommodation management platform.

Official domain: staypunch360.com

## Development principles
- All planned modules appear in navigation with Coming Soon status until implemented, tested and released.
- Unreleased features cannot execute live reservations, payments, or OTA synchronization.
- Changes use feature branches, pull requests, validation and review before merging.
- Booking inventory is authoritative and shared across the booking engine, PMS and channel integrations.

## Initial milestones
1. Foundation: responsive shell, authentication, property context, feature registry.
2. Direct booking engine and PMS.
3. OTA connectivity, revenue management and subsequent modules.

This repository is being initialized. No production modules are live yet.
